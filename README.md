# The Trading Desk v2

Replace your existing build.py with this version and add .github/workflows/update.yml.

V2 adds broader sectors, sector-vs-Nifty relative strength, representative sector leaders with 1D/5D performance, breadth, and news impact labels.

Setup: keep GitHub Pages on main -> /docs; then Actions -> Update Trading Desk -> Run workflow once. Scheduled run is 07:15 IST Monday-Friday.

Sector “money flow” is a proxy using performance, relative strength, breadth and volume; it does not prove institutional fund flow. Yahoo Finance data is unofficial; cross-check your broker before trading.
